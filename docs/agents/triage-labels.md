# Triage 标签

相关 skill 使用五种规范的 triage 角色。下表将这些角色映射到本仓库 Issue Tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签  | 含义                             |
| -------------------------- | ----------------- | -------------------------------- |
| `needs-triage`             | `needs-triage`    | 需要维护者评估该 Issue           |
| `needs-info`               | `needs-info`      | 正在等待报告者补充信息           |
| `ready-for-agent`          | `ready-for-agent` | 信息完整，可交由 AFK Agent 处理  |
| `ready-for-human`          | `ready-for-human` | 需要人工实现                     |
| `wontfix`                  | `wontfix`         | 不会处理                         |

当 skill 提到某种角色（例如“应用可交给 AFK Agent 的 triage 标签”）时，应使用上表中对应的本仓库标签。

如果本仓库未来调整标签命名，可直接修改表格右侧的“本仓库使用的标签”列。
