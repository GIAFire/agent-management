# 分类标签

这些技能使用五种规范的分类角色。本文件将这些角色映射到当前仓库问题跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 当前跟踪器中的标签 | 含义 |
| -------------------------- | ------------------ | ---- |
| `needs-triage` | `needs-triage` | 需要维护者评估该问题 |
| `needs-info` | `needs-info` | 正在等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由无人值守的智能体处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理该问题 |

当技能提到某个角色时，例如“应用可交由智能体处理的分类标签”，请使用上表中对应的标签字符串。

如果仓库实际使用其他标签命名，请修改右侧一列。
